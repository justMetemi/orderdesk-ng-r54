CORRECTION MADE
---------------
The public.get_public_catalog_options(p_slug text) function appeared in both:
- r5_2_universal_catalogue_checkout_migration.sql
- r5_2_2_service_digital_fulfilment.sql

The service/digital migration contained the corrected COALESCE fallback:
  COALESCE(jsonb_agg(...), '[]'::jsonb)

The older universal catalogue migration still contained an incomplete duplicate
function body. It could overwrite the corrected function if that migration were
applied after the service/digital migration. The duplicate function and its grants
have now been aligned byte-for-byte with the corrected definition in the service/
digital migration. Both copies expose the same fields, including service booking
metadata, and return an empty JSON array when no published products are found.
