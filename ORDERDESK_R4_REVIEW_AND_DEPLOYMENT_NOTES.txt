ORDERDESK NG R4 — REVIEW PACKAGE
================================

This is a review ZIP based on the uploaded OrderDesk_NG_R4_Product_Trial_Message_Fix.zip.
It is not deployed. No live Netlify site or Supabase database was changed.

CHANGES IN THIS PACKAGE
-----------------------
1. Platform-owner Online Store exemption:
   - index.html storeAccess() now applies the same owner ID exemption already
     present in the Settings and product-access checks.

2. Expired public storefront browsing:
   - Added orderdesk_r4_access_storefront_migration.sql.
   - It preserves the latest get_public_shop JSON structure from
     online_store_support_upgrade.sql and removes only the subscription gate
     from public shop reading.
   - Existing products, descriptions, prices, images, stock and shop details
     remain in the returned public data shape.

3. Checkout restriction:
   - Existing place_store_order SQL already checks
     has_orderdesk_access_for_business() before creating orders.
   - The migration updates that access function to include the platform owner.
   - initialize-paystack-store-order.js now checks owner/trial/active subscription
     before proceeding with Paystack setup/checkout.

4. Help & Support styling:
   - shop.html now applies a green glassmorphism treatment to the Help & Support
     cards on desktop and mobile, with improved contrast and focus visibility.

5. Existing product trial-expiry message:
   - The uploaded source already contained the requested ₦10,000/month upgrade
     message and Upgrade now action. It has been preserved.

IMPORTANT ITEMS NOT CLAIMED AS COMPLETED
----------------------------------------
- Automated WhatsApp alerts still require WhatsApp Cloud API credentials,
  approved templates and Netlify environment variables. Existing support in
  this project handles new_order and payment_success; this package does not
  claim to add all requested receipt-upload, verification and failure events.
- Free in-app event notifications for every requested payment/receipt event
  have not been added in this package.
- The SQL migration and frontend changes have not been run against your live
  Supabase database or deployed to Netlify.
- This package has not been tested against your live database, live Paystack
  account, or production environment.

SAFE REVIEW / DEPLOYMENT ORDER
------------------------------
1. Keep the original ZIP as your rollback copy.
2. Review this package and the SQL migration.
3. Back up the Supabase database before running any migration.
4. Run orderdesk_r4_access_storefront_migration.sql in Supabase SQL Editor.
5. Deploy the complete folder contents to Netlify only after approving the
   migration and reviewing the site.
6. Test with:
   - platform owner account;
   - active trial merchant;
   - active paid merchant;
   - expired trial merchant;
   - expired paid merchant.
7. Confirm expired stores can browse, but cannot create bank-transfer,
   pay-on-delivery or Paystack orders.

-------
