OrderDesk NG — Online Store update notes

Existing v3 features remain in place. This package adds the Online Store instead of replacing the application.

New files:
- shop.html — public storefront, cart, checkout, receipt upload and order tracking.
- online_store_upgrade.sql — additive database migration.
- schema.sql / schema2.sql — copies of the supplied baseline schemas for a separate test project.

Modified:
- index.html — adds Online Store owner navigation, store setup, product publishing and Online Orders management.
- sw.js — version bumped and shop.html added to the PWA shell.
- netlify.toml — adds /shop/<slug> rewrite to shop.html.

Preserved unchanged:
- admin.html
- netlify/functions/ai-followup.js
- manifest.webmanifest
- existing subscription UI/logic

No production Supabase or Netlify deployment was performed.
